**Модель лесного пожара**

  В данной модели исследуется состояние системы, в которой распространяется некоторое возмущение, переводящее систему в хаотическое состояние.
Пространство представляет из себя двумерную регулярную решётку размером N строк на M столбцов.

Особенности и параметры модели:

  - Окрестность: Неймана (4 соседних клетки, +-образная окрестность) или Мура (8 соседних клеток, квадратная окрестность);
  
 - Клетка может принимать 3 состояния s:
    - s = 0 – пустая клетка;
    - s = 1 – клетка с деревом;
    - s = 2 – клетка с горящим деревом.
  
  - Условие возгорания клетки с деревом:
    - В окрестности клетки не менее k горящих деревьев;
    - С некоторой вероятностью f в дерево бьёт молния (произвольное возгорание).
  
  - На месте сгоревшего дерева (дерево сгорает за один такт) образуется пустая клетка;
  
  - На пустой клетке с некоторой вероятностью p вырастает новое дерево;
  
  - За границами области нет деревьев (фиксированные граничные условия
  
  - Состояние обновляется синхронно.
  
  Распределение деревьев в области генерируется **случайным образом**, притом уже горящих деревьев не генерируется.



**Программная реализация**

  Программа имеет интерфейс в консоли IDE. При запуске программы в консоль IDE выводится меню вида:
  
    === КА лесного пожара ===
    1. Текущие параметры
    2. Ввод параметров
    3. Расчёт КА
    4. Выход
    =======================
    >Ввод: _
  
  Пункты меню:
  - Пункт 1: выводит текущие параметры заданные для модели.
  - Пункт 2: позволяет поочерёдно ввести собственные параметры для расчёта.
  - Пункт 3: запускает расчёт сетки клеточного автомата (КА) с заданными параметрами (или параметрами по умолчанию, если не был выбран п.2).
  - Пункт 4: завершает работу программы.

  Задаваемые (в п.2) параметры:
  - N - число строк, int, не менее 1;
  - M - число столбцов, int, не менее 1;
  - f - вероятность случайного возгорания, float, от 0 до 1;
  - p - вероятность случайного роста дерева, float, от 0 до 1;
  - tti - минимальное число горящих деревьев в окрестности для возгорания другого, int, не менее 1;
  - t - число итераций, int, не менее 1;
  - inter - задержка между кадрами анимации, мс, int, больше нуля;
  - areatype - тип окрестности, 0 - Неймана, 1 - Мура.

  В результате расчёта по п.3, выводом является график с последнего такта, а также анимация работы клеточного автомата "animation.gif", которая сохраняется в папке с программой.
